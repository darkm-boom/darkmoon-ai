
# DarkMoon AI

A simple desktop assistant for Linux.

## Features
- Search for files in a selected folder.
- Read text documents.
- Create basic summaries of text files.
- Enter commands in the assistant window.

## Requirements
- Linux Mint or a compatible Linux system.

## Run the app
Open a terminal in the extracted DarkMoon AI folder and run:

```bash
./DarkMoonAI
```

## Current status
This is an early version. The summarizer uses a basic text-selection method. Advanced AI features are planned for future releases.
